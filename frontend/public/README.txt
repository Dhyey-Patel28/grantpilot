GrantPilot logo asset pack

Recommended files to copy into your frontend/public/ folder:
- app-icon.png
- favicon.ico
- favicon.svg
- favicon.png
- favicon-32.png
- favicon-16.png
- apple-touch-icon.png
- android-chrome-192x192.png
- android-chrome-512x512.png
- site.webmanifest
- logo-mark.svg
- logo-primary.svg
- logo-primary.png

Use logo-mark.svg for a smooth true-vector mark.
Use logo-primary.svg or logo-primary.png for a full wordmark lockup.
Use app-icon.png for the app icon / sidebar mark.
Use logo-source-nano-banana.png only as the original visual reference.

Notes:
- PNG files are based on the selected Nano Banana logo and cleaned onto transparent/solid backgrounds.
- logo-mark.svg is a smooth true-vector redraw, not a jagged bitmap trace.
- logo-embedded.svg preserves the exact PNG look inside SVG, but it is not an editable vector redraw.
